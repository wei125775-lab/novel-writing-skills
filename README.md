# novel-writing-skills · 中文网文写作 Skill + 描写句库抽句管道（开源方法层）

从三本写作书**蒸馏方法**得到的一组可调用写作辅助 skill，外加一套用**你自己的语料**抽句建"描写句库"的管道脚本。本库只含方法与代码，**不含任何受版权保护的例句或词典内容**。

## 内容

| 目录 | 是什么 | 用法 |
|---|---|---|
| `writing-skills/save-the-cat-novel/` | 小说结构骨架：救猫咪 15 动点 × 10 故事类型（已做网文适配：一个完整弧/大卷≈一套 15 拍） | 规划长篇骨架、大纲卡壳、写歪定位时调用 |
| `writing-skills/webnovel-market-writer/` | 中文网文商业创作：免费大长篇 / 付费订阅 / 付费短篇三分支，女频·男频技巧去重合并，短篇平台投稿 | 开新书选题、写黄金三章、留钩子、上架变现 |
| `句库管道/` | 抽句管道脚本（Python）：`01_clean` 清洗切句 → `02_candidates` 信号词打标成候选 →（按采纳标准人工/子代理审）→ `03_build_lib` 落库；`04_scan_mood` 主情绪直给句补扫；`inspect` 分页浏览候选 | 拿你自己的小说语料，跑出私有「分类描写句库」 |

每个 skill 内含 `SKILL.md`（frontmatter 含触发词/不适用/source_book/tags/related_skills）+ `references/`。使用：把整个目录放进 `~/.claude/skills/` 即被 Claude Code 识别；若给其他写作 AI 用，读 SKILL.md 的 description 即可。

## 灵感来源与版权说明

方法蒸馏自公开售卖的写作书：**《救猫咪：小说创作指南》**（杰西卡·布罗迪）、**《网文写作变现》**（冰封 / 曹缦兮 / 鹿小策）、**《如何描写情感》**（安琪拉·阿卡曼、贝卡·帕格利希，即 The Emotion Thesaurus）。

- 本库只保留这些书里**可迁移的方法与写作框架**（15 拍结构、类型卡、商业选题逻辑、情绪写作规则等），全部为改写浓缩，**不复制原文句子**。
- 《如何描写情感》的 75 情绪词条信号词典、以及从盐选/实体书语料抽出的例句库，因属受版权内容，作者放在私有仓库、不在本库公开。想获得同款参考：自己备好语料，用 `句库管道/` 跑一遍即可生成私有例句库；词典部分请购原书。
- 使用时如涉及对某本书大段复述，请自行斟酌合理引用边界。
