# 10 故事类型卡——选一个"角色转变方向"，别再按题材分类

原书的关键转法：别按"科幻/都市/悬疑"这种**题材**分，按**主角经历的转变/中心主题**分。类型只决定一件事——故事该往哪立、必备元素缺不缺。两张提醒：

- **找最接近的，别求精确**。一本小说常常同时沾两三种；《悲惨世界》可以既算制度化又算超级英雄。纠结分类不如去检查"我这个方向最吃哪几个元素"。
- **类型会漂移，系列/多卷里每卷还可以不同**。作者自己的书从"遇到问题的家伙"改成"犯罪动机"再改成"超级英雄"；《饥饿游戏》三部曲三本三个类型。大纲阶段先选，写歪了再换不丢人。

每张卡给 5–8 个最能说明"这类型怎么立"的动点（取自原书逐拍拆解的畅销代表作），加一条网文对应。

---

## 1. 犯罪动机 Whydunit（侦探、欺骗与阴暗面）

- **核心转变**：一个角色（未必是侦探）追查一桩已成事实的罪案与藏在里面的黑暗秘密，最后被"为什么"逼出自己人性/道德的阴暗面。
- **必备元素**：①**侦探**——专业/业余/甚至读者本人皆可，但必须对这个案子**毫无准备**、且有理由被拖进来；②**一个秘密**——读者一路猜到底的钩子，会从一个小秘密滚成大雪球；③**黑暗的转折**——主角深陷其中，做出违背自己规则/道德的事。
- **不适合**：秘密不够大（读者猜到就没意思了）；案子与主角毫无个人关联（会有"这样吗，所以呢"）；纯机械解谜没有"人性阴暗面"可挖的。
- **代表作拆解（《火车上的女孩》）**：开场形象=酗酒失忆的女主在火车上幻想他人生活（不可靠叙述者）→ 陈述主题=她"拒绝面对现实"→ 催化剂=断片醒来带伤，不记得前夜 → 中点=嫌犯被捕（假胜），随即被放+尸体出现，升级成谋杀（风险提高）→ 坏人逼近=她又开始喝酒，和嫌疑人上床（**黑暗的转折**）→ 失去一切=被锁起来威胁杀害、真凶另有其人 → 灵魂暗夜=红发男人拼上最后记忆，**顿悟袭击者是前夫** → 尾声=与另一个受害者联手，反杀。
- **网文对应**：刑侦/悬疑/女频复仇/"马甲+身世之谜"。**钩子是"为什么"不是"谁"**——答案必须指向人性的某种暗面，主角自己也跟着脏一次手，才算把类型立住。

## 2. 成长仪式 Rites of Passage（当生活受阻时）

- **核心转变**：主角扛过一个人生必经的坎（死亡/分离/失败/失恋/中年危机/长大），最后接受一个残酷事实：**必须改变的是自己，不是生活**。
- **必备元素**：①**一个人生问题**——通常不是作恶招来的，活着就会遇到，普遍得人人共情；②**错误的解决方式**——主角靠逃避/转移注意力硬扛（《爱玛》不面对孤独，去给朋友做媒）；③**接受残酷事实**——真正的解法。
- **不适合**：问题纯属自找（那是惩罚故事，不是成长的痛）；主角一路得体应对、没有先逃避过（那没有"成长"可写）。
- **代表作拆解（《追风筝的人》）**：开场形象=接到电话，暗示"未赎之罪"→ 陈述主题=父亲说"不会为自己出头的男孩，将来一事无成"（主角的懦弱）→ 催化剂=目睹发小被强暴、自己逃跑没救 → 讨论=被内疚啃噬，试各种错误办法 → 进入第2幕=**错误方式**：栽赃发小偷窃、把人赶走 → 中点=父亲病逝（假败，升险）→ 失去一切=发小已死且是自己同父异母的弟弟、遗孤待救（死亡气息+真相）→ 进入第3幕=决定去喀布尔救人（领会"挺身而出"）→ 尾声深挖=和仇人对殴中第一次感到"被治愈" → 结局形象=替弟弟的儿子追风筝（回到开场意象）。
- **网文对应**：现实向年代文、重生/校园成长、都市失意中年、青春疼痛。注意网文读者要爽感——"接受事实"的落点通常是**主角选择了一条更难但更对的路并真的变强**，而不是停在淡然。

## 3. 制度化 Institutionalized（加入他们、离开他们，或毁掉他们）

- **核心转变**：主角身处/进入某个群体或体系（家庭/公司/门派/社会/政权），被逼做一个终身选择——**加入、逃离，还是摧毁**。
- **必备元素**：①**一个群体**——体系大到让内外的人都觉得"这就是全世界"；②**一个选择**——由三种角色驱动：**天真者**（新来的，读者借他学规则）、**白兰度**（体制内老手，早已暗中怀疑）、**公司人**（体系的化身，誓死保卫它、显得疯狂）；③**一次牺牲**——结局三选一：加入、毁掉、逃离（含字面/比喻的自杀）。
- **不适合**：主角没有真正的两难（选边太轻松）；故事只关个人成长、不触及群体疯狂。
- **代表作拆解（《相助》）**：开场形象=黑人女佣爱比琳（白兰度）带白人小孩 → 陈述主题=天真者斯基特问"你是否曾希望改变某些事"，爱比琳答"一切都很好"（抗拒）→ 三条线各自的催化剂（爱比琳被邀受访/斯基特收到写作建议/明妮被解雇）→ 进入第2幕=爱比琳答应受访，三人结盟 → 中点=女佣们排队来讲故事（假胜，但意识到被希里逮到的风险）→ 坏人逼近=公司人希里步步紧逼、各人私生活崩坏 → 失去一切/灵魂暗夜分散在三主角身上 → 尾声=书出版、毁掉这个制度 → 结局形象=爱比琳当众对希里站了出来（她曾是全场最不敢冒风险的人）。
- **网文对应**：宗门/家族/宫斗宅斗/职场/学院/国家队（"体制内新人 vs 老油条 vs 死忠"）。网文最吃"公司人"这一型——需要一个让人牙痒的、真心相信这套规矩的对手，主角赢他才等于赢下整个体系。

## 4. 超级英雄 Superhero（平凡世界里的不平凡）

- **核心转变**：一个**非凡**的主角发现自己活在平凡世界，必须接受自己注定特别/伟大，并为此付代价。
- **必备元素**：①**一种力量**——可以不是魔法，是"做好人的使命感/对一个目标的信念"这种异常坚定的东西；②**一个敌人**——与主角对位、甚至更强的对手，但敌人是"自封的英雄"，靠阴谋和伪装维持假象，缺主角那种真信仰；③**一个诅咒**——特别身份的代价，通常是"被误解/被孤立"，用来抵消主角的优越感、让读者同情他。
- **不适合**：主角一开始就自信强大被众人拥戴（没有"接受自己"的过程）；只有力量没有代价（读者会讨厌他）。
- **代表作拆解（《哈利·波特与魔法石》）**：开场形象=婴儿被放在仇视他的姨妈家门口 → 陈述主题=邓布利多"让他远离名气长大，准备好了再告诉他"（力量+诅咒）→ 设定=德思礼家受虐孤儿（停滞=死亡）→ 催化剂=海格告知"你是巫师" → 讨论=买装备、了解自己的名声（准备型）→ 进入第2幕=火车去霍格沃茨（旧世界→新世界）→ 乐趣与游戏=魔法学校爽点全兑现 → 中点=魁地奇首胜（假胜），斯内普疑云升险 → 失去一切=伏地魔即将拿到魔法石 → 尾声高塔意外=真凶不是斯内普是奇洛；深挖=力量在体内（母亲的爱），不靠外援 → 结局形象=回程火车上，不再是那个自卑孤儿。
- **网文对应**：天选之子/血脉觉醒/重生天才/被选中救世。最易犯的错是只写"爽"漏了**诅咒**——要让特殊身份一开始就带来排挤、追杀、代价（现代校园/宗门里被当怪物），读者才能共情。

## 5. 遇到问题的家伙 Dude with a Problem（通过最终考验）

- **核心转变**：一个普通得不能再普通的主角，被一个**突发的、并非自找**的灾难卷入，靠挖掘出自己都没意识到的潜能，通过最终考验。
- **必备元素**：①**无辜的主角**——他没主动要这个麻烦（麻烦越与他匹配越好：宇航员困火星 vs 律师困黑律所，问题要"几乎不可能"而别"不可能"）；②**突发事件**——明确、毫无预兆；③**一场生死战**——威胁个人/团体/社会存亡。
- **不适合**：麻烦是主角自己作出来的（那是"房子里的怪物"——分界问题：**这是谁的错？** 我们的错→怪物型，天降的错→本型）；问题大到主角毫无对应技能（"不可能"写不长）。
- **代表作拆解（《头号书迷》）**：开场形象=作家在疯粉家中醒来、剧痛濒死 → 设定=出车祸被"头号书迷"安妮所救实为囚禁 → 陈述主题="你欠我一条命"（讽刺：她逼他写出最好的书=救他的命）→ 催化剂=安妮发现他写死了她最爱的主角，翻脸 → 讨论=被逼烧掉手稿、答应写新书保命 → 进入第2幕=同意写《米斯里的归来》 → 乐趣与游戏=写作渐入佳境（假顺，他仍被囚）→ 中点=假胜（书写得极好）＋安妮抑郁暴露"她永远不会放我走"（升险）→ 失去一切=她杀了来救他的警察（死亡气息）→ 进入第3幕=地窖里发现点火液，想出逃生的"正确方式" → 尾声=烧稿诱她、打字机反杀（高塔意外：她没死又爬起）→ 结局形象=靠写作与恐惧共处。
- **网文对应**：穿越到陌生环境求存/无限流新手局/末世求生/废柴卷入大阴谋。**"问题与主角的匹配"是命门**——给主角的技能必须恰好够他挣扎着活，但又不让他秒杀全场。

## 6. 傻瓜成功 Fool Triumphant（失败者的胜利）

- **核心转变**：一个被低估、被忽视的失败者（"傻瓜"），因为天真和做自己，最终反过来戳穿并赢了那个看不起他的**权势集团**。
- **必备元素**：①**一个傻瓜**——温和到被所有人忽视（往往有**嫉妒的知情者**：唯一看出他潜力、暗中使绊的人）；②**一个权势集团**——傻瓜置身其中或被打进去的群体，二者不匹配才起火花；③**一种转变**——傻瓜通常**换身份/伪装/改名/换任务**（简·爱变家庭教师、灰姑娘换装），用假面骗过瞧不起他的人，最后摘面时证明"做自己才最强"。
- **不适合**：主角一开始就被所有人当回事（那是超级英雄）；有明确"被选中"光环的。
- **代表作拆解（《BJ单身日记》）**：开场形象=新年计划暴露她的自我嫌弃（傻瓜）→ 陈述主题=被已婚族嘲讽"这岁数怎么还没结婚"（权势集团+主题：她得学会自我接纳）→ 催化剂=坏男人上司发来调情短信 → 进入第2幕=明知他只想上床还是回应（错误方式）→ 中点=发现他劈腿（假败）→ 坏人逼近=换新工作、被故事B的马克约出去（马克爱的正是"没改造过的她"）→ 失去一切=妈妈卷入骗局 → 进入第3幕=明白"不必改造自己也能被爱" → 尾声/结局形象=回到日记体总结：计划全没完成，但这年过得很棒。
- **网文对应**：**废柴逆袭/扮猪吃虎/马甲文/隐藏大佬**——网文最肥沃的类型之一。核心是让"别人以为的废物"和"真实身份"形成反差，把打脸节奏拉满；别让主角自己也知道自己很牛（那就没有"无知的天真"当武器了）。

## 7. 伙伴之爱 Buddy Love（爱情/友谊的转变性力量）

- **核心转变**：主角遇见一个**对应的人**（恋人/朋友/宠物/甚至无生命的物），被对方永远地改变、变得完整。
- **必备元素**：①**不完整的主角**——缺一块，需要另一个人才能完整（注意先确认到底是谁的故事：转变最大/叙述者视角的那个才是第一主角）；②**对应的人**——与主角互补、有点特别，值得占整个催化剂动点；③**令情况变复杂的因素**——把两人分开/阻碍的东西（误会、身份差距、绝症、家族恩怨、社会反对、甚至对方不是人），它既让他们分离也让他们靠近。
- **不适合**：主角的改变不是由"另一个人"引起（判断法：**催化剂是且仅是一个存在的出现吗？** 不是→别归这类）；冲突不够、两人太早在一起（那 10 页就写完了）。
- **代表作拆解（《你是我一切的一切》）**：开场形象=全白的无菌房间（不完整主角：免疫缺陷囚于室）→ 催化剂=黑衣男孩搬来隔壁（天生对应者：动 vs 静、黑 vs 白）→ 讨论=他是谁？两人隔着窗户互动 → 进入第2幕=发邮件，关系正式开始 → 陈述主题/故事B=护士卡拉"每件事都有风险，什么都不做也有风险" → 中点=初吻（假胜），随即她为护他**冲出家门**（史上最大风险，want→need）→ 失去一切=夏威夷病发、心脏停跳（死亡气息）→ 灵魂暗夜=分手、绝望、"爱会杀死我"，随后收到医生邮件：她根本没病（顿悟）→ 进入第3幕=冒最大风险查明真相（是妈妈囚禁了她）→ 尾声=飞纽约书店重逢。
- **网文对应**：言情/耽美/无CP挚友/宠物文。别让复杂因素只是个"误会"，它最好是**贯穿全程、既拆散又撮合**的结构性障碍（阶级差/宿仇/绝症/身份对立）。

## 8. 瓶子里的魔法 Magic Bottle（一点点魔法会大有帮助）

- **核心转变**：一个普通人暂时被"魔法"（许愿/诅咒/鬼魂/换身/时间循环）影响，最后领悟：**改变生活的是自己，不是魔法**。
- **必备元素**：①**一个值得拥有魔法的主角**——要么灰姑娘式值得被赋能，要么傲慢鬼值得被报应（报应型记得在前 10–20 页安排"救猫咪时刻"）；②**一个咒语/施法**——必须**独特、好玩**，且**有明确规则**（作者不能中途变卦骗读者）；魔法原理不用解释太细，"为什么"比"怎么运作"重要；③**一个教训**——第 3 幕主角常在**不用魔法**的情况下做成关键事。
- **不适合**：魔法永久有效、直接解决一切（那没有教训可学）；主角本来就来自魔法世界/异世界（那是奇幻史诗，不是"普通人被魔法撞了一下腰"）。
- **代表作拆解（《我的闺蜜是幽灵》）**：开场形象=失意女骗父母自己过得很好（值魔法的主角）→ 陈述主题=父亲"分手后总觉得复合会完美"（她得学会向前）→ 催化剂=105 岁姨婆的鬼魂（年轻版）出现 → 讨论=我疯了吗（确认魔法为真）→ 进入第2幕=答应帮鬼找项链（进入"和鬼一起生活"的世界）→ 乐趣与游戏=用鬼的**规则**（只有她可见、能对人耳语施压）追查+撮合自己 → 中点=假胜（魔法让她复合+事业起色），故事A/B相交 → 失去一切=鬼/恋人/事业 24 小时内全丢 → 灵魂暗夜=发现名画里的女孩正是姨婆（顿悟）→ 进入第3幕=**鬼不在，她不得不无魔法行动** → 尾声=凭自己揭穿叔叔骗局、为姨婆正名。
- **网文对应**：**系统文/金手指流/时间循环/穿书/换身**。网文最容易踩的坑是"魔法无代价、无规则、永久强"——那会让故事在第 10% 就结束。要么给金手指设硬规则和反噬，要么按"教训"收尾：最后的高光是主角**脱离外挂**做成的事。

## 9. 金羊毛 Golden Fleece（公路旅行、追寻与盗窃）

- **核心转变**：主角（或团队）为寻找一样东西踏上旅程（真·公路或比喻义），找到的却是**自己**——奖品到最后贬值，旅程才是意义。
- **必备元素**：①**一条道路**——必须有可追踪的推进感（地图/记分牌/进度条），最好有**公路苹果**（胜利在望时让旅程暂停的路障，逼团队内省重策）；②**一个团队**——每个成员带一种主角缺的技能/态度（也可**单人羊毛**：沿路遇不同帮手）；③**一个奖品**——原始而有吸引力（回家/宝藏/自由/王冠），但会在旅程结束时贬值。
- **不适合**：主角没有"在路上"的推进感（原地打转不是旅程）；团队无功能（凑人头不如不要）。
- **代表作拆解（《玩家1号》）**：开场形象=交代未来世界与终极奖品（400 亿彩蛋）→ 陈述主题=损友"你们显然都需要自己的生活"（现实 vs 虚拟）→ 设定=现实生活烂透、绿洲里才能做人 → 催化剂=解出第一条线索 → 进入第2幕=下"恐怖之墓"拿铜钥匙 → 故事B=遇到暗恋对象阿尔忒弥斯 → 乐趣与游戏=三把钥匙三道门的解谜+被 IOI 追杀（兑现"80 年代彩蛋游戏"的承诺）→ 中点=派对告白被拒＋IOI 袭场（假败）→ 失去一切=IOI 连过两门、即将赢走绿洲 → 尾声高塔意外="大灾难"把他们都炸死（他有额外生命）→ 深挖=公开身份、宣布分奖金（奖品贬值、友情升值）→ 结局形象=在现实世界见到她本人，不想再登入绿洲。
- **网文对应**：**升级流/副本流/寻宝/公路/集齐七颗龙珠式**。网文的"道路推进"通常靠境界/地图/收集进度，天然好追踪；别让路上遇到的人只是过客——他们要么是队友、要么是镜子，帮主角最后认清自己。

## 10. 房子里的怪物 Monster in the House（不仅仅是一个恐怖故事）

- **核心转变**：主角被困在封闭空间里，与一个想杀他的"怪物"共处，最后发现**怪物是自己招来的**——必须面对这个罪，才能消灭它。
- **必备元素**：①**一个怪物**——有"超自然"的越界动机（疯狂/邪祟/科技失控都行），威胁不止性命还有"灵魂"；②**一栋房子**——封闭空间（房子/小镇/深海实验室/甚至主角自己），**主角必须逃不掉**才成立；③**一个罪过**——有人要为怪物的诞生/侵入/唤醒负责（傲慢、贪婪、冷漠……），罪常藏着消灭怪物的线索和主题；常配**半人角色**（与怪物交手过的幸存者/导师，负责交代背景，常死在失去一切）。
- **不适合**：主角完全无辜（那是"遇到问题的家伙"——**问一句：这是谁的错？**）；能随时开车逃走的（没封闭就没戏）。
- **代表作拆解（《心形礼盒》）**：开场形象=过气摇滚明星网购了一个"鬼"（收藏癖=他的冷漠）→ 陈述主题=女友骂"你这没同情心的混蛋"（缺爱是他的病根）→ 催化剂=鬼首次现身 → 讨论=他查清鬼是前女友继父、因他抛弃前女友而死缠 → 进入第2幕=决定主动调查鬼的来历 → 乐趣与游戏=鬼（催眠师）操纵身边人自杀，两只狗是他的护盾 → 中点=假败：鬼隔空催眠陌生人在餐厅杀他（风险升级）→ 失去一切=两只狗一死一重伤（护盾没了）→ 灵魂暗夜=梦中看见前女友死亡真相=自己罪过全貌 → 进入第3幕=回到老家，同时面对鬼和父亲的鬼（过去）→ 尾声=深挖：用"爱"开门（金色之门）把鬼拖走、救回女友 → 结局形象=录新专辑、结婚、帮酷似前女友的女孩（罪已赎）。
- **网文对应**：**无限流副本/规则怪谈/密室逃脱/都市怪谈/被自己罪业反噬的复仇**。判断一部"恐怖"到底归本型还是"遇到问题的家伙"，就抓**罪责**：主角或全人类有份，就是本型；这罪既给他招来怪物，也给他留出消灭怪物的钥匙。

## 一句话分型速记

- 谁干的、为什么这么干 → **犯罪动机**
- 活着的坎、接受事实 → **成长仪式**
- 选边：加入/逃离/摧毁 → **制度化**
- 我注定特别，但付代价 → **超级英雄**
- 天降大祸，我撑住了 → **遇到问题的家伙**
- 你们都看走眼了，我赢 → **傻瓜成功**
- 遇见你，我变完整 → **伙伴之爱**
- 魔法帮了我，但我靠自己 → **瓶子里的魔法**
- 上路找宝，找到自己 → **金羊毛**
- 怪物是我招来的 → **房子里的怪物**
