# 短篇与平台：付费短篇怎么投、怎么写、怎么变现

> 源书 P4 第十～十二章（曹缦兮）+ P1 版权开发章。短篇是全书"最实操"的一块：平台路径、导语、拆文、字数配比都有手把手细节。**时效提醒：平台收稿字数与分成比例会变，动笔前以官网约稿函/编辑征稿动态为准。**

## 0. 短篇市场画像（第十章）：值不值得干

- 优点：反馈快（过稿次月见收益）；框架好构思；沉没成本低（写废最多一万字，这篇不行换下一篇，还能换平台投）；无日更捆绑（适合兼职）。爆火三类型：**情感、悬疑、脑洞**（且常融合：如"恋爱脑穿进恐怖游戏"=言情×恐怖游戏脑洞）。
- 缺点：每篇都要新梗追热点（像自媒体一样，无连贯性=无存量消耗）；稿费波动大（上月上万下月归零常见）；读者黏性低（读完记不住作者）。
- 认知：爆火有随机性（靠推文博主带）；但"量"可破——收入稳定的作者都写过上百篇。短篇适合当练笔/副业入口，长篇才是长尾收入来源。

## 1. 六大平台与签约路径（第十一章第一节，重点知乎/番茄）

**知乎（盐选/盐言故事）**——公认知名度最高、推文认可度最高。
- 收稿字数 0.8 万–10 万，**短篇 1–2 万字为佳**；创意极好 3–5 万字也能爆。
- 三种投稿通道：
  1. **盐选作者平台后台投稿**：网页版→创作中心→盐选合作（未开通先申请盐选作者）→创建作品。需投全文（>8000 字），格式不用调。审核一般 20 个工作日内站内私信回复，超时太久可找盐选作者小助手礼貌催问。通过后签合同上架。
  2. **发布问答攒数据**（新手推荐入口）：找与小说类型吻合的高活跃问题，发 3000–5000 字（别发全文，全文被赞藏概率低），结尾留钩子在最精彩处戛然而止，引导互动。赞藏多了会被制作人看见主动来签约；即便没人看见，带数据回后台投稿过稿率也更高。
  3. **发布文章**：创作中心直接发文（前三四千字即可），有成绩后再用，新人不太建议。
- 签约方式：**作者经纪签**（高人气作者，预付保底后扣除）vs **作品独家签**（多数人，只签单部、不限写作自由、收益 50% 分成）。
- 上架与流量：先上架专栏（可自找推文博主推）→ 上架两三天后"免转付"（原来免费赞过的读者仍免费，此后新读者付费）→ 再被"分发"（个人分发/官方账号分发，官方分发数据常比专栏赞数高，稿费可观）。
- 收入构成：每月一结的稿费（按会员有效阅读计）+ 广播剧/有声改编收听 + 出版/影视改编版权。
- 问答选问题策略：跟小说类型吻合（别在虐文问题下发甜文，后期没法免转付）；选**回答少、关注多、浏览量高**的（竞争小+盘口大）；看 7 天内有没有新回答数据好的；别重复发、别在太多话题下发同内容（限流查重）；数据不好可重发，但改开头节奏+末尾钩子后再发，删除等深夜改"修改中"再删。

**番茄小说**——免费龙头，短篇模块刚起步，稿费中位数略低于知乎、热点稍滞后；但入口完善、与抖音/头条同家，未来流量倾斜可期。
- 收稿 4000–2 万字。投稿两通道：① 番茄作家助手/官网作家专区→"短故事"创作投稿；② 编辑邮箱内投（官网作家福利→联系编辑→短篇组附邮箱；或关注"番茄作家助手"公众号实时征稿政策）。
- 签约：内投由编辑告知流程（下载 App 实名认证→机器+编辑审核）；后台投稿要先达到数据要求获签约资格再申请。
- 稿费：纯分成 or 保底+分成（有历史成绩可申请保底）；分发在今日头条/番茄/抖音，稿费由头条广告收益、抖音收益、头条会员收益、番茄广告收益等构成。

**其余四家**（速览）：
- **UC 小说**：风格独树一帜，收 8000–3 万字；电脑端大鱼号创作者平台→"故事会"。有历史成绩可谈保底+分成，无则普遍五五；征文有奖金。
- **黑岩故事会**（含若初文学，女频向）：收 8000–2 万字，**对爆点要求严、上架卡点靠前（2000–3000 字）**，写时就留好钩子。内投为主，小红书可搜编辑邮箱；有的制作人只要开头 2000 字即可投，试错成本低。保底+分成/纯分成，次月 15 日发稿费。
- **咪咕文学**：收 8000–3 万字，主收第一人称；官网投稿时需用一句话介绍主线剧情。保底+分成/纯分成；推广一般、爆文概率小。
- **每天读点故事 App**：收稿更早、类型更多样（不限知乎风/第一人称）；VIP 保底（1000 元保底金）+分成或纯分成；已打通其他网站渠道分发。

**第三方（工作室/公司/个人）避坑**：第三方是先从平台五五、再按合同跟你分，作者拿得比直签平台少很多；被"买断"后后续分成与你无关；很多第三方只收稿上稿收割线上稿费、无版权运营。若在意版权运营，选大平台/老牌网站或挑有版权运营的第三方；投稿前查口碑防稿费不透明/延迟。

## 2. 导语 50 字（第十二章第二节，短篇生死线）

知乎露出的导语约 50 字；推文博主前几秒同理——不吸睛直接划走。三条铁律：
1. **只保留动作和台词，能简则简**：不堆华丽辞藻，不放大段背景和心理描写（背景后置，环境心理只在重要情节一笔带过）。
2. **不要留悬念，全篇最吸睛的梗毫不吝啬放上来**：有噱头才有人点进来，藏着掖着更没人看到。
3. **扒榜学结构**：常见爆款导语结构=悬念+反转+内涵（能第一时间调动情绪）。多读多拆，找手感。

## 3. 拆文方法（第十二章第三节，最见效的练笔）

找一篇爆款，按四个维度拆：**导语**（逐字逐句拆：背景/人物/情节/转折，数出场人物与转折个数）→ **人设**（拆大众设定之上叠加的特有设定）→ **结构**（拆起承转合：每部分作者在写什么、主角在做什么，每段一句话总结）→ **故事线**（通读后找主线副线）。自己拆比看别人拆好的更记得住。

## 4. 12000 字字数配比表（第十二章第一节，直接用）

短篇大纲"定起承转合"时按字数配内容。以 12000 字为例（非固定，看故事走向调整）：
| 字数区间 | 该放什么 |
|---|---|
| 500 字前 | 有亮点、有矛盾、有清楚的主线 |
| 500–2000 字 | 快速展开剧情，剧情叠加递增、情绪拉满，至少给 3–4 个爆点 |
| 2000–5000 字 | 故事持续升级；**注意卡付费点，留好钩子** |
| 5000–8000 字 | 一个大高潮（可能是主角高光时刻） |
| 8000–10000 字 | 一个反转，主角再遇一点危机 |
| 10000–12000 字 | 走向结局，升华主题 |

短篇大纲写法五步：定主题与亮点（一个出色的创新点成功一半）→ 定主角人设（越完整越好，性格/目标/生活环境/家庭背景/优缺点）→ 定配角人设（有威胁或助力的都写，反派可能决定出彩与否；没配角可不写）→ 定起承转合（按上表配字数）→ 定内在逻辑（因果/事件递增/铺垫与冲突是否得当）。

## 5. 短篇节奏与文笔速效（第十二章四节，浓缩）

- **文笔 vs 情节：剧情大于文笔**。爆款多文笔一般但节奏快、爆点接一个。新人两大病：堆砌华丽辞藻 + 怕交代不清开头啰唆。环境/心理/天气描写全是一笔带过、为剧情服务；重点剧情/高潮/转折/反转才多着墨。笔力=用通俗流畅的文字把故事讲明白并牵动情绪。
- 节奏慢的 6 个解法：① 别在构思阶段就否定自己的梗，先写完再删繁就简；② 开篇直接爆冲突、关键人物出场（示范结论：一句话开场就把"丫鬟冒充我身份与借住书生珠胎暗结"的冲突+人物全抛出来）；③ 每段情节都为主线与主角情感变化服务，"稳准狠"直指结局；④ 情绪别太平，反派施压要逐级加重、主角"见招拆招"，正反来回拉扯着写（交互过程），别让读者泡在同一种情绪里；⑤ 用对话推进（细节/动机由对话带出，直接升级冲突，比叙述更耐看更紧张）；⑥ 扒榜对比爆款节奏，学其口吻节奏表达自己的创意（慎防抄成抄袭）。
- 提高文笔 8 小技（速记）：形容词替换成具体感官描写 / 善用新鲜比喻（避免"红得像苹果"）/ 想象笔是摄影机拍电影（一镜到底、由远及近）/ 用具体名词（白杨树不说行道树）/ 加动作细节让画面有层次 / 别每个动词都挂副词 / 偶尔语序措置增韵味 / 情绪写成画面动作（开心="甩了甩辫子，嘴角上扬"，难过="低下头，红了眼睛"）。
- 词不达意：多输入积累词汇 + 灵感先用最简话记下（可用录音），攒够词量再回头打磨。

## 6. 文笔之外：环境与情感描写的公式（第十二章六节）

- 环境描写 7 用（短篇，句句要起作用）：反差烘托（主角大悲时环境写得极美好，世界没因他改变→更衬惨；分手当天艳阳高照）；一致烘托（惨+阴雨"惨上加惨"）；当转场介质（两处远隔场景用同一场大雨/物品连起来=平行蒙太奇）；加强情绪（紧张=针落可闻，恐惧=空间逼仄）；增强人设（家装色调/摆设暗示主人）；第一视角"目之所及"（直白语言列"我"看到听到什么，拉代入）；做呼应锚点（高潮时下雪/见月，收尾再提一笔把读者情绪拉回前文）。
- **情感公式**（源书引《如何描写情感》，写任何强烈情绪都按这 5 层想）：① 外部信号（身体反应，情绪越强反应越烈）；② 内部感觉（生理性本能反应）；③ 精神反应（思维模式）；④ 体现强烈/长期情感的信号（长期后果：食欲不振/绝望）；⑤ 体现受压抑情感的信号（掩饰/不自知时的表现：转身离开/中断谈话）。示范（悲伤）：哭肿的脸和眼睛 / 胸口痛闷 / 不愿交流想独处 / 绝望食欲不振 / 为平静中断谈话。找到主角核心情感→按层配反应→读者代入。

## 7. 版权变现渠道与价码（P1 第三章，长篇短篇都适用）

版权是"被动收入"里的大头，来源与大致行情：
- **实体书出版**：晋江系网文出版最多。一般按版税（印量正比），签约给首印量版税，几万元级，网站抽成后到作者手里，常不如一个月稿费；3–6 个月后发放，卖完加印才续。能出版的两类：热度极高不愁市场 / 质量够出版线。
- **有声书**：比实体书好卖。签约后网站运营，稿费栏单独列"有声/听书渠道费"（番茄=番茄畅听）。收入弹性大：几百到几千元/月，收听量大则更多。
- **漫画**：多为畅销级作品才改编；上线后反向带动原著流量。成本高，数据不好可能停更。
- **短剧（风口）**：两种盈利——现成小说卖短剧版权（2–3 万元/部，作者不参与）；作者写原创剧本（保底分成，新人 1–2 万元，播出好后续有分成；或买断）。短剧=矛盾前置+情绪爆发+爆点密集，看短剧能学设置爆点与节奏。
- **影视剧**：版权费几十万到上百万元级，是版权里最肥的，但周期极长（完结→卖出→拍摄→播出）。古言近年影视化反响好。卖影视版权除了成绩好，还要看有没有改编成影视的可能与品质。
- 渠道现实：版权开发集中于晋江/起点/爱奇艺文学等大站，番茄/七猫也在发力；多数普通作者到不了版权阶段，先靠稿费养活自己，"手停口停"是常态——这也是为什么老作者开书爱选常青树题材（完结后长尾几个月到一年，约连载期月稿费十分之一），或同人自带流量。
