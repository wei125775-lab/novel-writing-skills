# 大纲与命名：骨架怎么搭，名字怎么起

> 源书 P2 第八章"女频小说的大纲设计"（字段最全）+ P3 第九章第六节"男频常见大纲分类"（三类大纲）+ P2 第六章开头与悬念章（章纲/地图）。两份大纲视角合并：女频那套是"写给编辑看的完整档案"，男频那套是"自己用的三类骨架"，写前先想清四件事：世界观、关键人物、作品定位（题材分类/热度/读者人群）、核心卖点（金手指/意义非凡的配角）。

## 一句话总则

大纲 = 防跑偏 + 拉长篇幅的骨架。开篇阶段可以不管大纲、专心主线与主角对手戏；作品有字数积累后再靠大纲转场续命。但**大纲重要，不必要**——思路不清时直接动笔写，拿到读者反馈再回头补大纲，别把时间耗死在纸面规划上（P3 冰封原话：新人写大纲常常由点化线由线化面，老手可以反过来）。

## 一、命名与简介（P2 大纲第 1/4 节）

### 书名 10 法（对着平台榜单学，新手不玩文艺）
1. 称谓取名：点明人物身份——《太子妃升职记》。
2. 故事主线取名：一句话概括全书——《穿进赛博游戏后干掉boss成功上位》。
3. 小标题式：开头加类别助快速归类——《重生之我在古代当皇后》。
4. 吸睛取名：堆新奇元素让人想点——《大佬气场一米八，圈内咖位三十八》。
5. 人设取名：点主角人设——《长安第一美人》。
6. 性格取名：提炼主角性格元素——《大小姐她总是不求上进》。
7. 情节取名：把最吸睛的情节拎出来当书名——《错嫁高门，主母难当》。
8. 反差取名：书名里放反差词——《替身爱人的逆袭之路》。
9. 提炼核心卖点取名：人设/结局/情节里最核心的一点——《回京后，神算大小姐名满天下》（结局向）。
10. 热词取名：塞高岭之花、白月光、萌宝、逆袭这类市场热词。
    - 简洁文艺风（人物《花千骨》/地名《楼兰往事》/古诗词《千山暮雪》/氛围《黎明前他会归来》）老作者才玩得起；**新人没粉丝基础，书名要囊括尽量多元素换流量，等流量起来再改书名。**

### 简介四段四要素（环境、人设、冲突、悬念）
- 第一段：背景一笔带过 + 人物现状或困境。
- 第二段：强化矛盾冲突 + 描述主线（提炼最精彩情节）。
- 第三段：突出人物性格（可用小剧场/对话） + 公开主角身份或点金手指。
- 第四段：收一个有悬念或反差的结尾，让读者想点开正文。
- 原理：把书里闪光点全拿出来，写出差异化，别藏着掖着。

## 二、女频"编辑档案式"大纲字段（P2 第八节全流程）

投稿给编辑的大纲不需要章纲，但以下字段写全：
1. **书名**（用上面 10 法）。
2. **风格**：HE/BE/正剧/轻松/搞笑/暗黑，只写一个。
3. **标签**：写最突出 3–4 个给书定位（例：《鸣蝉》=天作之合，穿越时空，青梅竹马，正剧）。
4. **故事简介**：见上四段四要素。
5. **故事主线与辅线**：主线=一片叶子的主脉络（核心、最根本的冲突）；辅线=主线过程中开出的分支。另设**情感线**：主角感情线是主要感情线，配角感情线是辅助感情线（例：《风吹半夏》主要感情线=许半夏×赵垒；辅助=童骁骑×野猫等）。
6. **人物设定**：姓名/年龄/外貌/性格/三观/喜好/能力；出生环境、家庭背景中独特值得写处；家庭概括与社会地位。男女主越详细越好，含命运转折点、技能/弱点。要点：有亮点别太完美。
7. **故事梗概**：800–1200 字。四要素=主要人物、时间地点、重要情节、结局。提炼"能严重影响主人公命运走向的事件"，写清"发生了什么事→之后人物关系/命运怎么变"，细枝末节不写（示范：把《知否》梗概拆成四要素——人物=盛明兰；时间地点=宋/京城；重要情节=藏拙成长、为母报仇、结识顾廷烨；结局=夫妻相爱相守）。
8. **章纲（细纲）**：给编辑的大纲不用写，**写给自己用**。每章提炼 1–2 个剧情点（都是关键剧情、能提炼重要人物信息），**结尾要有钩子设悬念**。不会写就参考影视剧分集剧情——一集可拆几章，前几章细纲越细越好。
9. **大纲要有新意**：编辑看过成百上千故事，基础模板没问题后，必须再添几个让人耳目一新的创意点才过稿。

## 三、男频三类大纲（P3 第九节第六节，按自己习惯选）

写大纲前都先过"世界观 / 关键人物 / 定位 / 核心卖点"四问（都市文世界观要架空，大势力背景对应现实需架空，小势力如明星圈/艺人公司/主播群体会细）。

### 1. 人物大纲（老作者偷懒最爱，适合发散思维）
先立人物，让人物碰撞推出剧情，进而疏通主线/支线/暗线。人物 = 信息面板（例证已浓缩）：姓名、年龄、身份背景、性格特点、能力、目标、个人经历（含为何如此/童年阴影/转折点）。主角/配角/反派各一张卡。
- 常规型故事线 = 从人物处境推：废柴技能练到极致仍被看轻 + 好友发现新地图 + 反派兵临城下 + 众臣轻视 → 主角赌命亮底牌 → 一战成名得认可。
- 反模板故事线 = 同开局换选择：主角不硬刚，借反派清剿迂腐势力，再收尾重洗牌。
- 平和型故事线 = 主角提前化解 + 为反派平冤收服人心。
- 用法：一鱼三吃，同套人设能推三条线，写作自由度最高。

### 2. 剧情大纲（新人最常用，简单好用）
推进式做剧情概括：先定整体主线骨架 → 把剧情发展填进骨架 → 大纲用完再往下接。至少完整构建一个大剧情：切入事件→敌人是谁→什么困境→遭了哪些被动事件→如何化被动为主动→解决了得什么收获→新配角/反派怎么出场因何与主角结缘。一个大剧情写完前，要提前铺垫下一个剧情怎么接。理想态：第一个事件开头与最后一个事件结尾闭环。
- **名场面写法**（简单粗暴的剧情大纲技巧）：先想好几个"名场面/主角高光时刻"，让前面的剧情不断铺垫推动、最终促成名场面（例：定名场面"一百单八将聚义梁山"，再想各路好汉如何在聚义前结识、被谁凝聚）。小剧情填充大剧情，大剧情推向名场面。
- 注意：**被动事件下的小剧情可随时出现；主动事件下的大剧情必须提前铺垫**，免得读者看完大高潮过完瘾就走（《葫芦兄弟》：救爷爷是名场面级大剧情，中间各娃被抓是小剧情；爷爷死前抛"消灭妖怪"新目标续上大剧情，蛇蝎死后青蛇复仇再开第二部——大剧情套大剧情的连锁示范）。

### 3. 地图大纲（老手/想写系列作才用）
以地图/世界观搭大纲。先设定世界：主角启程前世界发生过什么变迁、历史时间线（历史大事件后面常造成影响落到主角头上）；再列出各地区势力背景、势力人物、势力间关系、关系引发的大事件与前因后果。
- 范本《斗破苍穹》斗气大陆：乌坦城→魔兽山脉→塔戈尔沙漠→云岚山（前段），后转黑角域/北域/中域/南域/虚空，每到一块新地图就是一段新成长+新机缘+新势力（书里逐城列了主角获得什么）。地图推进到边界还能接续作（斗破→武动→大主宰）。
- 书判：新人没强人物/剧情掌控力前别主用地图大纲，容易本末倒置。

## 四、写大纲时的通用提醒（两频合并）

- 每本都先明确核心卖点（金手指/独特人设），后期最忌写着写着把核心卖点写淡写丢（详见 `男频框架.md` 节奏段——卖点淡化是长篇崩盘的常见病）。
- 人物设定要防崩：别让角色做他本不该做的事。动笔问自己"以他的性格三观，在那种环境下会怎么做"，不是以你自己的三观。
- 受欢迎的人设类型：性格反差（对外杀伐决断/对女主温柔）；有独特记忆点（特定喜好/习惯性动作/常佩小物）；四人组（两主角两配角）性格有明显对比更鲜明。
- 长线续命三件套（女频百万字章）：**列大纲 + 转换地图 + 开副线**。地图转换以女主/主角身份升格为分割点（《知否》：盛府庶女→侯府主母，身份换任务换），空间/时间一变，新鲜感与陪伴感都续上；副线（配角感情线/剧情线）只丰富情节不喧宾夺主。
- 梗概与章纲要克制：梗概砍掉细枝末节，章纲每章只留 1–2 个有效剧情点，别记流水账。
